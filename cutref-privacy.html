cutref (컷 레퍼런스) 개인정보처리방침

Privacy Policy for cutref · 시행일 Effective 2026-11-23 · 서비스 주소 masoduregi07.github.io/bookmarks

cutref는 드로잉 연습용 무작위 레퍼런스 이미지를 보여 주는 개인 · 비상업 웹 앱입니다. 로그인하지 않으면 모든 기록은 사용자의 브라우저에만 저장됩니다.

cutref is a personal, non-commercial web app that shows random reference images for drawing practice. Without signing in, all data stays in the user's own browser.

1. 수집하는 정보 · Information we collect

  • 구글 로그인(선택): 이메일, 이름, 프로필 사진 주소 · 기기 간 동기화에 계정을 구분하는 용도로만 사용
  • 동기화 데이터(로그인 시): 연습 기록, 보관함 목록, 링크, 앱 설정, 사용자가 직접 올린 레퍼런스 이미지
  • 핀터레스트 연결(선택): 사용자가 허락한 경우 해당 계정의 보드와 핀 정보를 읽기 전용으로 불러옴 (boards:read, pins:read) · 핀터레스트 연결 토큰은 서버에만 보관
  • Google sign-in (optional): email, name and profile picture URL, used only to identify the account for syncing between devices.
  • Synced data (when signed in): practice log, saved items list, links, app settings and reference images the user uploads.
  • Pinterest connection (optional): with the user's permission, the app reads that account's boards and Pins read-only (boards:read, pins:read). The Pinterest access token is kept on the server only.

2. 이용 목적 · How we use it

사용자 본인에게 레퍼런스 이미지를 보여 주고, 사용자의 기기들 사이에서 데이터를 맞추는 데만 씁니다. 광고, 분석, 프로필 작성, 판매에 쓰지 않습니다. 핀터레스트에 글을 쓰거나 핀 · 보드를 만들거나 바꾸지 않습니다.

Only to show reference images to the user and to sync the user's data across their devices. No advertising, analytics, profiling or selling. The app never posts to Pinterest or creates or changes Pins or boards.

3. 보관과 제3자 · Storage and third parties

동기화 데이터와 토큰은 Cloudflare(Workers · D1 · R2)에 저장됩니다. 로그인 비밀번호나 핀터레스트 세션 쿠키는 받지도 저장하지도 않으며, 로그인은 구글 · 핀터레스트의 공식 OAuth로만 합니다. 이미지는 각 원본 사이트(FILM-GRAB, Sakugabooru, Unsplash, Pexels, 각 게임 팬 위키, 핀터레스트 등)에서 불러옵니다.

Synced data and tokens are stored on Cloudflare (Workers, D1, R2). The app never receives or stores passwords or Pinterest session cookies; sign-in uses Google's and Pinterest's official OAuth only. Images are loaded from their original sites (FILM-GRAB, Sakugabooru, Unsplash, Pexels, game fan wikis, Pinterest, etc.).

4. 삭제와 연결 해제 · Deletion and disconnecting

  • 앱의 설정 › 계정에서 로그아웃하면 그 기기의 동기화가 멈춥니다.
  • 핀터레스트 연결은 앱에서 해제하거나 핀터레스트 설정 › 앱 권한에서 언제든 취소할 수 있습니다.
  • 서버에 저장된 데이터 전체 삭제는 아래 연락처로 요청하면 처리합니다.
  • Signing out in Settings › Account stops syncing on that device.
  • The Pinterest connection can be removed in the app or revoked at any time in Pinterest's app permissions.
  • To delete all data stored on the server, contact us below.
